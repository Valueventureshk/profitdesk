Ad bills

Meta's figure comes straight from Meta. Google doesn't share its balance, so ProfitDesk takes the last time Google charged each account on your Airwallex cards (the charge carries the account number) and adds up the spend since, hour by hour, from Google. A monthly bill on the 1st pays for last month only, so those count from the 1st. Where Google adds tax (e.g. GST), set it once in Settings → Stores → Google tax.

Connections

Add an Airwallex account

In Airwallex: Settings → Developer → API keys → Create restricted key. Give it view access to Balances and Financial transactions only, then paste its Client ID and API key here.

One sub-account per line: its name (optional) then its Account ID (starts with acct_). Copy each ID with the copy button next to it in Airwallex.

Add a PayPal account

At developer.paypal.com, log in with the PayPal business account, switch to Live, open Apps & Credentials → Create App, then under Features tick Transaction search. Paste the app's Client ID and Secret here.

Held money (reserves and monthly-limit holds) is placed on the day PayPal releases it: 60 days after the sale for the reserve, 21 days for the monthly limit.
