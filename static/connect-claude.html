Use EcomVital from the Claude app (desktop, web, phone) or Claude Code

1. Make your connector link

The link is yours: Claude can only see and do what your EcomVital access allows, and everything it changes is logged under your name. Anything that changes something (prices, Google Ads…) is proposed first and only happens after you say yes in the chat.

Your connector link (shown only now, copy it)

Treat it like a password: anyone with this link can use EcomVital as you. Don't paste it in chats or emails. Lost or shared it? Remove it below and make a new one.

2. Add it to Claude

Claude app (claude.ai, desktop or phone):

  1. Open Settings → Connectors (or Customize → Connectors).
  2. Click Add custom connector.
  3. Name: EcomVital · URL: paste your connector link · Add.
  4. In a new chat, click the + / tools button and make sure EcomVital is switched on.
  5. Try: “Using EcomVital, how did all stores do yesterday?”

Claude Code: tell it “add the EcomVital connector with this link” and paste the link there.
