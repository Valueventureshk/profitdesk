Add a Shopify store

Each store connects through its own small ProfitDesk app in Shopify. Make one per store, then paste its details here.

How do I get these?
  1. Go to dev.shopify.com, pick the organization that owns the store, then Create app → Start from Dev Dashboard. Name it ProfitDesk.
  2. On Versions, set App URL to http://127.0.0.1:8787, scopes to read_orders, and Redirect URL to http://127.0.0.1:8787/auth/shopify/callback. Untick "Embed app in Shopify admin" if you see it. Click Release.
  3. On Settings, copy the Client ID and Client secret.
  4. Open Distribution, choose Custom distribution, enter the store address, leave the Plus box unticked, and click Generate link. Copy the Install link.
  5. Paste all four here and click Connect store. Shopify asks you to approve; click Install and ProfitDesk finishes the rest.

Leave the install link empty only for an app that is already installed on the store. To retry a store you've already added, just type its address and click Connect store; its keys are saved.

iPhone widget

Your chosen figures on your iPhone home screen or lock screen, through the free Scriptable app. No App Store app needed.

AI

Claude Haiku 5.5 sorts every support email (customer, inquiry, legal or other; SCM and/or CS) and builds the tickets. It uses your own Anthropic API key.

Support mailboxes

Each store's support inbox, read every 2 minutes into the Inbox desk. ProfitDesk never marks emails as read, moves or deletes them.

People

Owners see and change everything. Everyone else only sees the desks you give them: Read & write can work in them (upload invoices, approve prices), Read only can only look.

Processing fees

Estimated per order from how it was paid, using these standard rates for a Hong Kong PayPal and Airwallex account. They come out of profit as their own line, so each store's Other costs % should now cover only product, shipping and packaging.

Store groups

Group stores to see them blended together, e.g. Meta stores, Google stores, Multiple channel stores. A store can be in several groups.
