Which products show this chart. The most specific wins: product, then collection, tag, product type, vendor, then “all products”.

Preview

Switch a store on to show its size charts on product pages. ProfitDesk adds a small script to that store (no theme editing), and the pop-up uses the store's own fonts. The language follows each store's tracking-page language (SCM → Settings).

Create a size chart from an image

Upload the supplier's size chart (screenshots from 1688, AliExpress, Taobao… Chinese is fine). The AI reads it into a clean table.

Create a size chart

Start from a template (you can change every number), a blank chart, or a supplier's image.

Import size charts

An export from Panda Size Chart, Kiwi or ProfitDesk (.json). Charts named after a product are linked to that product in the store you pick and set Active; the rest come in as Draft.
