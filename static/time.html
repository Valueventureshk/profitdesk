EcomVital Time for Mac and Windows

Setting it up (each person, once)

  1. Download the right file above and open it.
    • Mac: unzip, drag EcomVital Time into Applications, then right-click → Open the first time (it isn't from the App Store). When asked, allow Screen Recording and Input Monitoring / Accessibility in System Settings → Privacy & Security, then quit and reopen it.
    • Windows: run the file. If Windows shows “protected your PC”, click More info → Run anyway.
  2. Sign in with your EcomVital email and password.
  3. Pick the task you're working on (optional) and press Start. Press Pause for breaks and Stop at the end of the day.

What it records, only while started

  • Time worked, and each minute whether the keyboard / mouse was used (counts only: never what you typed).
  • The app and window title in front (e.g. “Chrome · Shopify”).
  • One screenshot of all screens at a random moment in each 10-minute block. You can remove one of your own screenshots within a few minutes if something private was on screen; that's logged.
  • Screenshots are deleted after 30 days; hours stay.
