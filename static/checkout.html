Your own payment page with subscriptions, paid through Airwallex. Paid orders go into Shopify as normal.

Settings

Airwallex key, payment notifications and test mode

In Airwallex: Developer → API keys → Create restricted API key, name it “EcomVital Checkout”, tick Payment Acceptance (read and write), inside the account the money should land in (Cutehome Australia). Paste the Client ID and API key here. Never in chat.

Payment notifications: Developer → Webhooks → Add webhook, URL , events payment_intent.succeeded and payment_intent.payment_failed. Then paste its secret here.
